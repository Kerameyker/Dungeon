# Hollow Spire

3D данж-кроулер від третьої особи на Unity 6 (C#): піднімайся поверх за поверхом, розвивай навички меча, перемагай боса кожного поверху. Оригінальна гра у стилі «вежі з поверхами та скіл-системою».

## Запуск (2 кроки)

1. У Unity Hub створи новий проєкт **Unity 6 (6000.x) → 3D (URP)** (підійде й Built-in). Закрий проєкт-шаблон і **заміни папку `Assets`** вмістом папки `Assets` з цього архіву.
2. Відкрий проєкт → меню **Game → Setup Project** (створює порожню сцену `Main`, додає її в Build Settings, налаштовує Linear і шейдери) → натисни **Play**.

Сцена порожня навмисно: гра сама будує камеру, освітлення, гравця, HUD і данж під час запуску. Усі ассети (текстури, моделі з примітивів, звуки, музика) генеруються кодом.

Потрібні пакети (є в стандартному шаблоні): Universal RP або Built-in, uGUI, Input System (необовʼязково, підтримуються обидві системи вводу), Test Framework.

## Навички та зброя

Чотири типи зброї, кожна з власним темпом, дальністю, комбо та **4 навичками**: Sword (збалансований), Rapier (швидкий, більше криту), Great Blade (повільний, важкий), Dagger (дуже швидкий, часті ухилення). Набір навичок на панелі змінюється разом зі зброєю в руках. Навички **прокачуються використанням** (рівні 0-5: +6% шкоди та -4% перезарядки за рівень). Унікальна навичка **Twin Tempest** (клавіша 5) відкривається сюжетом на 10-му поверсі: у лівій руці зʼявляється другий клинок.

## Лут та екіпіровка

З ворогів і босів випадає екіпіровка п'яти рідкостей (Common ... Legendary). Три слоти: зброя, броня (5 стилів), талісман (5 стилів). Предмет підбирається, коли підходиш до нього: іде в рюкзак (20 місць); одягати треба самому (I). **Вигляд героя залежить від екіпіровки**: форма клинка за типом і стилем, броня (шкіряна куртка, кольчуга, латна броня, плащ вартового, лускатий жилет), талісман, світіння за рідкістю та рівнем покращення. У рюкзаку видно порівняння з одягненим.

## Місто, кузня, квести, збереження

Місто **Hollow Haven**: цілитель Oleen (повне лікування), торговець Brannoc (купити зілля, Return Crystal, Revive Token, випадкову екіпіровку; продати речі), коваль Dorn (покращення предметів +1...+10, ціна: золото та Ember Shards; з +5 невдача знижує рівень), клерк гільдії Tessa (дошка квестів, до 3 активних) і брама в вежу (E; стрілки або колесо обирають поверх; F при першому поході вмикає **Hardcore**). Прогрес зберігається автоматично (рівень, XP, золото, осколки, зілля, екіпіровка, рюкзак, навики, квести, прапорці сюжету, розвідані боси, hardcore). Файл `hollow_save.json` лежить у `Application.persistentDataPath`; видали його, щоб почати заново.

## Вежа

20 поверхів «першого сезону», чотири біоми по 5 поверхів (Sunken Crypt, Green Ruin, Ember Depths, Void Stair) зі своїм кольором, освітленням, декором і музикою. Боси: звичайні мають 2 смуги здоров'я з новою фазою, віхові (5, 10, 15) мають 4 смуги, фінальний **The Architect** (20) має 5 і викликає підмогу. Під час бою з босом двері кімнати запечатуються; вивчений бос (після перемоги) отримує +10% шкоди від вас, удар у спину ×1.25. Кристали: **Return Crystal** (T у бою, 1.5 с, переривається шкодою), **Revive Token** (автоматично воскрешає на 50% HP). Напарниця **Miri** приєднується після боса 2-го поверху: після оглушення ворога зʼявляється вікно Switch (G): вона завдає потужний удар, а ваші перезарядки скорочуються вдвічі.

Сюжет (оригінальний) грає діалогами на віхах: пролог, знайомство з Miri, гільдія Ashen Oath, зрада, відкриття Twin Tempest, фінал з вибором «піти чи залишитись».

## Вигляд і анімація

Процедурна анімація (ходьба, стійка, падіння), м'які тіні, вогонь і пил частинками, біомні прикраси (мох і гриби, лавові тріщини, кристали порожнечі), постобробка URP (bloom, віньєтка, тонмапінг), HUD зі «скляними» панелями: рамка гравця, панель навичок з радіальним перезарядженням і майстерністю, зілля/кристали, смуги боса, мінікарта з маркерами, банери, діалоги.

## Структура

```
Assets/
  Scripts/Core/      чистий C# (генератор данжів, BFS, формули бою, прогресія) — asmdef Game.Core, без UnityEngine
  Scripts/Runtime/   Game, PlayerController, Enemy, Projectile, Chest, DungeonBuilder, CameraRig, Hud, ProcAssets, PostFx, Sfx, Fx, Pickups, GameInput
  Scripts/Editor/    ProjectSetup (меню Game → Setup Project / Build Windows Player)
  Tests/EditMode/    юніт-тести Core
  Tests/PlayMode/    димовий тест: гра стартує і працює 3 с без помилок
Docs/GDD.md          дизайн-бриф і числа балансу
```

## Тести та збірка з командного рядка

```
Unity -batchmode -nographics -projectPath . -executeMethod Hollow.EditorTools.ProjectSetup.Setup -quit
Unity -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -logFile -
Unity -batchmode -projectPath . -runTests -testPlatform PlayMode -logFile -
Unity -batchmode -projectPath . -executeMethod Hollow.EditorTools.ProjectSetup.BuildWindows -quit
```

## Як розширювати

- **Новий ворог:** додай значення в `EnemyKind`, запис у `EnemyCatalog` (GameRules.cs) і `case` з візуалом у `Enemy.Build()`.
- **Нова навичка:** запис у `SkillCatalog` + `case` у `PlayerController.SkillRoutine`; HUD підлаштується сам.
- **Баланс:** усі числа в `GameRules.cs` (Progression, CombatMath, каталоги) та в GDD.

## Відомі обмеження

Проєкт згенеровано без редактора Unity: код перевірено компіляцією зі стабами API та юніт-тестами Core, але не запускався в самій грі: див. розділ перевірки в CLAUDE.md. Постобробка (PostFx) потребує URP; у Built-in її треба прибрати.
