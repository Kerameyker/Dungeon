# Hollow Spire (Unity 6, URP)

Original 3D dungeon crawler. Everything is generated by code: meshes from primitives, textures, sounds, UI. The scene is empty; `Hollow.Game` bootstraps the game at runtime.

## Rules for working here
- No imported art/audio assets. Build them procedurally (see `ProcAssets`, `Sfx`, `Fx`).
- `Assets/Scripts/Core` = pure C# (asmdef `Game.Core`, no UnityEngine): rules, generation, items, tests. `Assets/Scripts/Runtime` = Unity code.
- Put game logic and numbers in Core and cover them with tests in `Assets/Tests/EditMode`.
- Gotchas: with `using System;` + `using UnityEngine;` write `UnityEngine.Object`; do not rely on runtime `_EMISSION` (flash via `ProcAssets.Tint`); check `GraphicsSettings.currentRenderPipeline` before using URP-only shaders; `Sprites/Default` is in Always Included Shaders.
- Setup: menu Game > Setup Project. Tests: see README (batchmode commands).
- Player-facing text and README are in Ukrainian.

## Команда агентів
Описи агентів лежать у `Docs/agents/`. Щоб Claude Code їх бачив, скопіюй їх у `.claude/agents/` (або попроси його: "перенеси Docs/agents у .claude/agents").

Делегуй окремі частини роботи спеціалізованим агентам:
- `game-designer`: механіки, баланс, економіка, нові системи (логіка в Core + тести).
- `narrative-designer`: сюжет, лор, діалоги, квести, тексти предметів і босів.
- `visual-artist`: процедурна графіка, матеріали, світло, частинки, постобробка, анімація.
- `gameplay-programmer`: керування, камера, бій, ШІ, інвентар, збереження, хаб, UI.
- `sound-designer`: синтезовані звуки й музика.
- `qa-reviewer`: незалежна перевірка ПІСЛЯ змін (тільки читає й запускає тести).

Типовий цикл: game-designer описує систему, gameplay-programmer реалізує, visual-artist і sound-designer додають вигляд і звук, narrative-designer додає тексти, qa-reviewer перевіряє.

## Перевірка без Unity (compile-check)
- Core: `cd Tools/coretest && dotnet run` (44 тести, очікується `failed 0`).
- Усі Core + Runtime проти стабу UnityEngine у трьох варіантах (legacy input, Input System, netstandard2.1): `bash Tools/fullcheck/build.sh` (очікується `0 Error(s)` тричі). Стаб (`UnityCore.cs`, `UnityUI.cs`) відтворює реальні сигнатури Unity 6; якщо Unity не скомпілює щось, чого стаб не знає, додай відсутній член у стаб за документацією.
- Гру в самому Unity ще не запускали. Перший запуск: Game → Setup Project → Play, перевір Console на помилки, потім пройди: місто → вежа → бос 2-го поверху (Miri) → магазин/коваль/дошка квестів.
